# Spec 031 Evidence

This directory records the evidence used to select and verify Spec 031 changes. Paths in `manifest.json` are repository-relative and contain no credentials or private machine paths.

Evidence states:

- `verified_code`: confirmed directly in source at the recorded baseline.
- `observed_artifact`: supported by a retained log, output, or fixture.
- `reported_unverified`: reported externally but the complete reproducible artifact set is not retained.
- `superseded_claim`: contradicted by source and prohibited as an implementation premise.

The retained 1IEP fixture is an offline parsing/post-docking regression. It does not select a new biological protocol and does not prove affinity, selectivity, mechanism, or efficacy. Unknown preparation parameters remain unknown.

No NMRbox/HPC execution, upload, or remote mutation is part of this evidence package.
